# 대거폴 온라인 튜토리얼 한국어 번역 데이터

**상태: 번역 데이터 완성 / 게임 코드 미연결 / 인게임 검수 전**

- 번역된 튜토리얼: **69 / 69페이지**
- 분류명: **13개**
- 튜토리얼 메뉴·팝업 UI 번역 초안: **19개**
- 원문: `src/systems/tutorialCatalogue.js` (2026-10-14 작업 브랜치 기준)
- 한국어 번역 본문: [`locales/ko/tutorials.ko.json`](../../locales/ko/tutorials.ko.json)

## 유의사항

**이 JSON 파일은 현재 대거폴 온라인이 인식하는 번역 팩 파일이 아닙니다.**

온라인 번역 팩의 로더는 `Text/*.csv`, `Text/Quests/*-LOC.txt`, `Text/Books/*-LOC.txt` 및 일부 `Fonts`만 인식합니다. 튜토리얼은 `src/systems/tutorialCatalogue.js` 안에 직접 작성되어 있으므로 이 JSON을 기존 ZIP에 단순 추가해도 적용되지 않습니다.

게임의 퀘스트 진행, 팝업 트리거, 저장 데이터, 스킬과 온라인 규칙에는 손대지 않았습니다. `main` 브랜치에도 반영하지 않았습니다. 기존 유니티 한국어 패치와 온라인 통합 ZIP 역시 그대로 유지됩니다.

## 검수

```bash
node tools/ko/check_tutorial_translations.mjs
```

검사 항목:

- 원문·번역 **69개 ID 일치**, 중복/누락 없음
- 제목, 표시 조건, 본문, 추가 팁 존재 여부
- 본문/추가 팁의 **배열 길이 및 순서 일치**
- `{Inventory}`, `{MoveForwards}` 등 **입력 키 바인딩 토큰의 정확한 보존**
- 페이지에서 사용하는 분류명 번역 존재 여부

**이 테스트는 텍스트 구조의 안전성을 확인합니다. 문맥에 따른 오역과 화면 줄바꿈은 아직 실제 게임에서 검수하지 않았습니다.**

## 게임에 실제 적용하려면

게임에 코드를 추가해 데이터가 실제로 로드되도록 해야 합니다. 안전한 최소 변경 범위는 다음과 같습니다.

1. 번역용 데이터만 지연 로딩하고, 사용자의 언어가 한국어일 때만 대응 페이지 문구를 찾습니다.
2. `tutorialText()` / 튜토리얼 목록 UI의 표시 문구만 번역 데이터로 바꿉니다.
3. 페이지 ID, 그룹 ID, 기존 영어 원문, `markTutorialSeen`, `noteFirstUse`, 저장 포맷, 키 바인딩 처리 로직은 **변경하지 않습니다**.
4. 한국어가 없거나 로딩에 실패하면 기존 영어를 그대로 표시합니다.
5. 튜토리얼의 자동 팝업, 다시 읽기, 검색, 입력 키 표시, 팝업 끄기/켜기 기능을 회귀 테스트합니다.
6. 공식 `daggerfalljs.dev`에 적용하려면 **원본 프로젝트 개발진의 병합 또는 배포**가 필요합니다. 유니티 번역 팩에 넣는 것으로 공식 사이트의 실행 코드가 바뀌지 않습니다.

분할 검수용 파일은 `locales/ko/tutorials/`에 있으며, **실제 기준 파일은 `locales/ko/tutorials.ko.json` 하나**입니다.
