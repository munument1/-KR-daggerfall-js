# DFO 온라인 전용 UI 한국어 번역 초안

> **번역 데이터 전용 작업입니다. 게임 실행 코드를 수정하거나 한국어 패치 ZIP의 동작을 바꾸지 않았습니다.**

## 원문 추적과 검수

각 JSON에는 `source_file`, `entries`가 있습니다. 번역 항목은 `id`, `line`, `en`, `ko`로 이루어지며 설정 번역은 **원래 설정 키**(`key`)도 함께 보존합니다.

```bash
node tools/ko/check_ui_translations.mjs
```

검증 기준:

- 원문의 해당 줄에서 **실제 영어 문구를 확인**
- 번역 비어 있음 / 중복 ID 점검
- `{variable}` 형태 플레이스홀더 비교
- 설정 항목 171개를 원본 `LABELS` 목록과 대조하고 모든 설정 키를 보존

**원문 표시 문자열의 정적 1차 번역입니다.** 캐릭터 생성의 가변 문장, 장비 조작 메시지, 소셜 기능의 동적 알림 등은 아직 남아 있습니다. 번역 품질에 대한 전체 인게임 검수도 아직 아닙니다. `id`와 `line`은 초안 검수 및 후속 코드 연결을 돕는 위치 추적 정보이고 게임에서 실제 조회하는 키가 아닙니다.

## 향후 현지화 연결 시 주의

- 현재 공식 게임은 이 JSON을 자동으로 불러오지 **않습니다**. 이 파일을 통합 한국어 ZIP 안에 넣기만 해서는 해당 UI가 번역되지 않습니다.
- `settingsCopy.js`의 설정 ID, `enhancedChargen.js`의 상태 ID와 생성 흐름, `socialPanel.js`의 서버 요청/응답 규약, `enhancedInventory.js`의 장비 슬롯 식별자는 절대 번역해서는 안 됩니다.
- 표시 직전 텍스트만 바꾸는 **별도 검증된 표시용 연동**이 필요합니다. 게임의 저장 데이터, 네트워크, 퀘스트와 튜토리얼 팝업 동작은 그대로 유지해야 합니다.
- 공식 웹사이트 `daggerfalljs.dev`에서 한국어가 적용되려면 공식 개발진이 연동 코드를 반영해야 합니다.
